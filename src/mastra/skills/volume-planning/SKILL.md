# 卷与章节卡

- 当前卷明确起点、主要目标、压力来源、关系变化、升级或损失、中段翻转和卷末钩子。
- 使用角色档案确定人物弧检查点，使用连续性账本确定当前真实状态；计划中的变化不能当作已经发生。
- 开篇三章分别完成：建立压力与主角欲望；暴露特殊杠杆与代价；交付首次可见变化并打开更大威胁。
- 每张章节卡必须同时包含即时目标 `goal`、主要阻力 `resistance`、关键转折 `turn`、角色推进 `characterShift`、可见回报 `payoff` 和章末牵引 `hook`，任何一项都不能省略。`characterShift` 写本章迫使谁作出什么选择或让哪段关系发生何种净变化，不写泛泛情绪。
- 相邻章节必须有因果，不能连续重复同一种冲突。
- 保留可调整空间，不预写全部场景台词。
- 同一次规划为范围内每章生成一个固定横轴张力节点，参考全书曲线设计峰谷。节点写明主导情绪、情绪强度、剧情功能和理由；分数只表达相对走势，不机械规定正文强度。
- 作者锁定的节点是硬边界。AI 优化只调整未锁定节点；除非作者明确要求“整条替换”，否则不得修改、删除或重排锁定节点。
