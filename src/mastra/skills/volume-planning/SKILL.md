# 卷与章节卡

- 当前卷明确起点、主要目标、压力来源、关系变化、升级或损失、中段翻转和卷末钩子。
- 开篇三章分别完成：建立压力与主角欲望；暴露特殊杠杆与代价；交付首次可见变化并打开更大威胁。
- 每张章节卡必须同时包含即时目标 `goal`、主要阻力 `resistance`、关键转折 `turn`、可见回报 `payoff` 和章末牵引 `hook`，任何一项都不能省略。
- 相邻章节必须有因果，不能连续重复同一种冲突。
- 保留可调整空间，不预写全部场景台词。
