# 章节写作

- 全自动开书的质量重写仍然只执行当前章节卡：`repair` 保留已成立的事件结果和连续性，修复被证据定位的问题；`replan` 先重新组织本章目标、阻力、转折、因果链和章末钩子，再输出完整新正文。不得用删短、回避冲突或降低兑现强度来绕过验收。

- 开头迅速进入行动、压力或决定，不用天气、醒来、照镜子和背景说明惯性开场。
- 主角必须主动尝试、选择或承担后果；本章至少让局面、关系、信息、风险或资源发生一次不可撤回变化。
- 场景由前一结果触发，中段升级阻力或改变路径。
- 上一章正文只用于承接已发生的结果；不得复制、近似改写或重新表演上一章段落和主要事件。
- 只执行当前章节卡。开场必须位于上一章结尾之后，并形成不同于上一章的新目标、阻力、转折和净变化。
- 同时读取本章及相邻章节的张力节点，把张力、主导情绪和剧情功能当作方向约束；通过事件选择与节奏自然实现，不在正文中输出分数，也不为追分破坏人物动机和因果。
- 角色档案描述长期设计，连续性账本描述当前真实状态；不得把计划中的秘密揭露、关系翻转或人物弧终点提前写成已经发生。
- 角色首次进入主要场景时，从档案选取两三个可观察的外貌与辨识特征，借动作、视角和场景自然呈现；后续只在辨认、情绪或行动需要时复用标志性细节，不重复整段人物介绍。新增长期角色必须在正文中留下至少一个可被角色档案引用的外貌辨识点。
- 对话改变信息、关系、策略或压力，角色声音符合身份与目的。
- 通过具体动作、感知、停顿和选择呈现情绪，避免总结腔、排比口号和解释性旁白。
- 结尾形成真实下一章牵引：揭示、威胁、艰难选择、关系翻转或带代价的回报。
- 只输出完整正文，不输出标题、提纲、自查和说明。
