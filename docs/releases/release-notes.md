# 版本更新说明

## 2026-10-15 · 作者审批与生产恢复加固

### 优化

- 提案原文和批准、拒绝决定持久保存在作品中；重复批准保持幂等，不能篡改提案后沿用原 ID，也不能重新应用已拒绝的提案。
- 作者继续生产时确认当前卷计划和张力曲线版本；确认后修改规划会使旧许可失效，章节只有在独立验收通过、章节顺序和依据版本仍有效时才能推进进度。
- 机制迁移提案在创建和批准时重新检查作品规划与章节范围，作品依据变化后需重新生成提案。

### 修复

- 修复同一本书并发保存或提交时丢失状态的问题；正文、账本和进度提交失败时回滚，中断后首次读取恢复未完成提交，并保留发生冲突的作者修改。
- 修复章节生产可能覆盖作者保护内容或尚未登记的作者文件的问题，限制通用提案直接创建章节或修改内部审批记录。
- 修复任务取消、失败或重试后，旧运行的迟到结果仍可能写入或影响新任务的问题；拆书任务的启动竞争、取消信号和结果提交一并加固。
- 修复首次全自动开书初始化 Skill 绑定失败的问题，并保留仅授权前三章的模式约束。
- 修复自定义章节切分规则可能长时间阻塞服务的问题；规则验证超时后返回可重试提示，并保留原有规则。

### 升级说明

- 缺少新生产授权记录的旧活动任务需要取消后重新启动；未登记到作品中的历史待审批提案需要重新生成。已有正文和作者文件无需迁移。
- 当前按单服务进程使用，不支持多个服务实例同时写入同一作品目录。

验证：173 项单元/集成测试、16 项 E2E、类型检查、Web 与 Mastra 构建，以及构建后真实 HTTP 提案审批流程全部通过；未调用外部模型。

## 2026-10-07 · 开书与拆书能力整理

- 新增：从公开榜单趋势进入快速或全自动开书，记录作者明确选择的偏好；拆书洞察可形成限定章节范围的结构迁移提案，并经作者批准后使用。
- 优化：章节质量验收最多自动重写两次；模型瞬时故障可重试，长篇拆书按上下文预算分组并保留已完成结果。
- 修复：作者偏好和市场缓存默认留在本地，不随代码提交。

## 2026-09-29 · 市场趋势历史缓存

- 市场趋势每次获取后按采集时间保存本地快照，支持选择历史时间查看榜单，并保留对应的题材观察和开书方向。
- 历史快照可直接复用开书方向，也可重新生成分析；兼容已有的最新榜单缓存，更新时保留旧数据。
- 拆书阶段聚合按章节分析的 Token 大小自动分组，保留卷边界和已完成的章节缓存，避免长阶段超出上下文限制；进度按实际分组数量展示。
- 输入处理器拦截请求时显示具体原因，上下文超限不再误报为模型结构化输出失败。
- 阶段与宏观聚合的证据位置由程序从原文核验和计算，避免模型填写无效偏移导致整阶段失败；失败提示准确标明所在环节。

## 2026-09-01 · 市场开书、偏好恢复与结构迁移

- 新增市场趋势页：保留番茄、起点、晋江公开榜单的原始元数据证据，并由独立 Agent 生成题材观察、阅读感觉卡、快速开书和仅覆盖前三章的全自动开书入口。
- 开书对话增加直觉偏好、选项、喜欢与不喜欢记录；模型瞬时故障会自动重试，失败任务可从最近稳定章节一键恢复。
- 拆书结果增加七大体系、70 维结构雷达；可把 1–3 条洞察转为机制级约束提案，经作者批准后限定作用于后续章节，来源或作品权威文件变化时自动失效。
- 章节质量链升级为最多两次自动质量重写，任务启动时同时锁定作品状态、Skill、作者偏好和机制迁移版本，避免长任务运行中上下文漂移。

## 2026-08-25 · 张力曲线与网文开书增强

- 新增全书和分卷目标张力曲线，可在作品工作台拖动、键盘调整、锁定、撤销和保存节点；作者修改受到保护，AI 优化以候选曲线对比呈现。
- 章节独立验收会同步记录实际张力、主导情绪、剧情功能和正文证据，并在分卷曲线上叠加实际走势，提示平淡、高压疲劳、高潮不足、兑现过晚和目标偏离。
- 章节生产在首次建立当前卷计划时同时生成逐章张力目标，暂停等待作者确认后再写正文；章节写作和验收都读取相邻张力目标作为方向约束。
- 拆书库增加标准、剧情和完整分析预设，可限定章节范围；结果重组为结构化小节并支持按需生成角色深研档案。
- 章节切分支持作者自定义锚定正则，也可让分析模型根据标题样本建议表达式；保存规则后可重建切分并保持原文完整覆盖。
- 开书灵感改为五种网文连载发动机，候选必须明确频道题材、核心优势、前三章首次兑现、可重复升级循环和稳定追读回报，减少文学梗概式方向。
- 所有可见思考过程、工具说明和最终回复统一要求使用简体中文。
- 补全蓝图与角色规划的账本合同，明确关系必须使用字符串数组，避免首次开书提案因关系对象格式错误而失败。

## 2026-08-19 · 拆书闭环与创作工作台完善

- 修复短参考文本推荐预算低于系统下限而无法启动的问题；预算越界时给出明确提示，不再显示通用失败。
- 修复阶段聚合采用模型自拟 ID 导致后续找不到分析文件的问题；失败任务会回到可重新拆解状态，并复用已完成的逐章批次。
- 全局拆书库入口纳入顶栏正常布局，窄屏不再与创作 Skill、主题和模型按钮重叠。
- 作品工作台增加 Markdown 可视化/源码双模式编辑、独立角色档案与角色当前状态展示，保持作者保护和保存语义不变。

## 2026-08-18 · 全局长篇拆书

- 新增全局拆书库，支持导入 UTF-8/GB18030 的 TXT、Markdown（最大 20MiB），先确认章节切分、Token 估算和硬预算，再启动模型任务。
- 新增 `reference-deconstruction` Mastra Workflow 和无记忆、无工具的拆书 Agent；不用向量库，按逐章全量遍历、阶段/宏观聚合、全书综合和证据复核运行，深度模式可追加结构、人物、节奏/钩子专项复扫。
- 原文、切分与历次分析全部本地版本化保留，支持全书、阶段、章节和限定原文证据下钻；全局同时只运行一个拆书任务，可追加预算或取消并保留中间结果。
- 模型设置新增 `analysis` 档位，未配置时回退到 Critic 或默认模型。
- `novel-agent` 新增只读参考报告能力。“应用到作品”只生成作者审批提案，不自动修改蓝图、角色档案、正文或连续性账本，并明确禁止复制参考作品专名、设定、情节组合与表达。

## 2026-08-17 · v0.2 内核重写

- 将能力平台和固定工件流水线重写为本地小说创作工作区。
- 永久删除旧作品与旧运行记录；保留模型设置和 Windows DPAPI 加密密钥，不提供旧生产链迁移。
- 权威作品格式升级为 schema v2，仅保留蓝图、连续性账本、卷计划、稳定章节、工作区和导出。
- 收敛为一个主创作 Agent、一个独立 Critic、六个通用工具和一个 `novel-production` Workflow。
- 打通蓝图里程碑批准、前三章连续生产、作者保护、逐行补丁批准、暂停恢复和 TXT 导出。
- 普通作者界面移除能力目录、Agent Profile、Tool Manifest、Workflow 列表、Prompt Manager 与 Trace/Span；模型设置保留，Studio 仅供开发使用。
- Windows 开发启动会先隔离上一次 Mastra 构建产物，避免 DPAPI 原生模块文件锁导致 Studio 无法启动。
- 作者工作区统一为文件树、当前文档和 Agent 三栏布局；开书阶段也立即显示灵感、设定、参考资料和导出分组，不再等待对话结束。
- 右侧 Agent 面板支持拖拽和键盘调整宽度，并在本机记住用户选择；窄屏自动恢复纵向布局。
- 新增全局 Skill 库：六个官方 Skill 幂等种子、派生/自定义/ZIP/Git HTTPS 导入、草稿编辑、frontmatter 与路径校验、试运行、不可变发布版本、历史回滚和归档。
- 作品新增 `workspace/skill-bindings.yaml`，可按 Agent、任务和固定版本启用 Skill；Workflow 解析后锁定版本，避免运行中的创作方法漂移。
- Skill 编辑器支持 `SKILL.md`、references、scripts 和 assets；资产可预览、替换、下载。未配置隔离 Sandbox 时只允许读取和发布，不暴露脚本执行。
