# 版本更新说明

这里维护项目完整的用户可见更新历史。根目录 [README.md](../../README.md) 只保留最新一次更新，完整历史请以本文件为准。

## 更新历史

### 2026-08-12

- 新增提示词工作台：可按创作阶段浏览提示词、编辑和保存草稿、对比官方模板、预览实际发送内容，并在确认后发布自定义版本。
- 重构作品工件栏，支持搜索、状态筛选、章节分组展开和完成进度查看，让长篇创作过程更容易定位与管理。
- 增加创作服务启动中的连接反馈与重试入口，减少本地服务刚启动时的空白等待。
- 优化长篇生产上下文装配：在固定预算内保留全部声明依赖，并优先提供当前章节计划与连续性信息。
- 改进运行失败后的恢复操作，以及首页和创作界面的动态反馈与交互细节。

### 2026-08-11（首个独立可运行版本）

- 提供面向新手作者的聊天式开书体验，可以从没有想法、模糊点子或阅读感觉出发，由创作搭档逐步整理为可批准的开书预设。
- 打通小说简报、故事圣经、世界设定、角色阵容、卷战略、卷骨架、章节规划、正文生产、质量修复、连续性提交和 TXT 导出的单书串行链路。
- 所有创作事实由版本化 Markdown/YAML 工件与小说状态记录承载；模型记忆和运行快照不会替代权威作品数据。
- 已提交工件支持 Markdown 排版预览和源码编辑；作者保存的修改会自动受到保护，并让依赖它的下游内容进入待刷新状态。
- 模型设置支持完整 Provider/模型目录、连接测试和任务模型覆盖；Windows 密钥使用当前用户范围的 DPAPI 加密保存。
- 运行任务支持流式进度、人工批准、取消、中断识别和安全恢复，服务退出不会覆盖权威工件。
- Mastra Studio 使用独立的本地可观测性存储，可查看日志、指标、追踪和实体发现结果。
- 重做作者工作台首页与主题系统，强化新建作品、继续创作和移动端布局，支持书卷暖色与纯白简约主题。
- 优化聊天式开书流程：讨论期间不再过早提示确认开书，作者明确结束讨论后才整理可审阅的开书方案。
- 创作搭档提出有限候选方向时，可生成 2–4 个快捷选项；点击即可发送包含完整意图的自然语言选择。
- 新增章节范围与自动导演能力，可选择逐项确认或自动推进，同时修复运行中断后的活动任务释放与恢复判断。
- 创作工件支持更清晰的推荐下一步、Markdown 排版预览和就地源码编辑，作者修改仍受保护并正确传播下游失效状态。
