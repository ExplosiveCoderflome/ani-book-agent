# 版本更新说明

这里维护项目完整的用户可见更新历史。根目录 [README.md](../../README.md) 只保留最新一次更新，完整历史请以本文件为准。

## 更新历史

### 2026-08-16

- 作品详情页升级为小说生产工作台：开书讨论、生产导航、工件阅读与编辑、运行状态和对话线程各自归位；桌面端充分使用工作区宽度，移动端保持可用的折叠布局。
- Agent 对话切换为 Mastra 原生 Thread Signal 流，保留真实文本、推理、工具调用、工具结果和审批状态；刷新后历史用户消息也会稳定显示。
- 对话现在形成完整开书执行链：作者明确结束讨论时，Agent 会整理可编辑的开书预设；预设确认后，Agent 可启动服务端判定的当前合法生产步骤。
- 新增当前作品范围内的文件管理与资产上下文入口，可查看工作文件、快速编辑 Markdown，并将选定内容带入后续对话。
- 新增创作能力和运行统计视图，展示已启用的 Agent、工具、Workflow、真实 Trace、Span 和 Token 数据。
- 运行投影直接读取 Mastra Workflow Run，页面刷新继续通过权威 `activeRunId` 恢复；不再依赖应用内运行事件总线。
- 保留书卷暖色主题，新增跟随系统与夜晚配色，并将既有纯白主题调整为专业黑白风格，无需迁移已保存设置。

### 2026-08-15

- 作品详情页升级为小说生产工作台：灵感期保留完整对话，开书后使用生产导航、中央工件区、可折叠对话区和底部运行状态。
- 新增统一 Workspace Projection，运行、审批、阻断和领域下一步均由服务端组合，刷新页面不再依赖前端保存运行 ID。

### 2026-08-13

- 新增卷进度工作台：在对话顶部集中显示当前卷、章节范围、稳定章节数和推荐下一步，展开后可查看每卷进度、卷间承接与完本验收状态。
- 进度工作台直接读取权威小说状态，兼容旧版作品；卷范围配置失败会在当前界面明确提示并可重试。

### 2026-08-12

- 新增完本验收门：最终卷完成后会检查稳定章节、质量债、未兑现承诺和连续性异常，只有验收通过才会标记整部小说完本。
- 新增卷间承接包：完成非最终卷后先整理已兑现内容、不可逆变化和下一卷入口，并自动注入下一卷骨架与首章上下文。
- 长篇生产现在支持按卷配置章节边界：每卷完成后自动进入下一卷，最终卷完成后明确进入完本状态，并可导出稳定章节 TXT。
- 自动导演会遵守当前卷范围，避免跨卷越界；卷骨架按卷独立保存，旧版作品仍兼容原有固定卷骨架。
- 新增提示词工作台：可按创作阶段浏览提示词、编辑和保存草稿、对比官方模板、预览实际发送内容，并在确认后发布自定义版本。
- 重构作品工件栏，支持搜索、状态筛选、章节分组展开和完成进度查看，让长篇创作过程更容易定位与管理。
- 增加创作服务启动中的连接反馈与重试入口，减少本地服务刚启动时的空白等待。
- 优化长篇生产上下文装配：在固定预算内保留全部声明依赖，并优先提供当前章节计划与连续性信息。
- 改进运行失败后的恢复操作，以及首页和创作界面的动态反馈与交互细节。

### 2026-08-11（首个独立可运行版本）

- 提供面向新手作者的聊天式开书体验，可以从没有想法、模糊点子或阅读感觉出发，由创作搭档逐步整理为可批准的开书预设。
- 打通小说简报、故事圣经、世界设定、角色阵容、卷战略、卷骨架、章节规划、正文生产、质量修复、连续性提交和 TXT 导出的单书串行链路。
- 所有创作事实由版本化 Markdown/YAML 工件与小说状态记录承载；模型记忆和运行快照不会替代权威作品数据。
- 已提交工件支持 Markdown 排版预览和源码编辑；作者保存的修改会自动受到保护，并让依赖它的下游内容进入待刷新状态。
- 模型设置支持完整 Provider/模型目录、连接测试和任务模型覆盖；Windows 密钥使用当前用户范围的 DPAPI 加密保存。
- 运行任务支持流式进度、人工批准、取消、中断识别和安全恢复，服务退出不会覆盖权威工件。
- Mastra Studio 使用独立的本地可观测性存储，可查看日志、指标、追踪和实体发现结果。
- 重做作者工作台首页与主题系统，强化新建作品、继续创作和移动端布局，支持书卷暖色与纯白简约主题。
- 优化聊天式开书流程：讨论期间不再过早提示确认开书，作者明确结束讨论后才整理可审阅的开书方案。
- 创作搭档提出有限候选方向时，可生成 2–4 个快捷选项；点击即可发送包含完整意图的自然语言选择。
- 新增章节范围与自动导演能力，可选择逐项确认或自动推进，同时修复运行中断后的活动任务释放与恢复判断。
- 创作工件支持更清晰的推荐下一步、Markdown 排版预览和就地源码编辑，作者修改仍受保护并正确传播下游失效状态。
